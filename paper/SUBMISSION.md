# Submitting the paper

Nothing has been submitted anywhere. This file lists the steps and the options found on 2026-10-03.

## Build

```bash
python paper/make_figures.py                     # figures + derived_numbers.json from results/*.json
cd paper
SSL_CERT_FILE=/etc/pki/tls/certs/ca-bundle.crt ~/.local/bin/tectonic -X compile main.tex   # -> main.pdf
```

Tectonic uses XeTeX. arXiv compiles with pdfLaTeX; the preamble only uses packages that work with both
(IEEEtran, newtxtext/newtxmath, graphicx, amsmath, booktabs, url, hyperref, xcolor), but a pdfLaTeX build has
**not been tested** on this machine (no TeX Live installed). Upload and check arXiv's generated PDF before
announcing.

## arXiv (preprint)

1. **Account.** Register at https://arxiv.org/user/register. Use the FAU address (an `@fau.de` student address)
   if possible: arXiv says an institutional email address expedites endorsement
   (https://info.arxiv.org/help/endorsement.html, read 2026-10-03).
2. **Category.** Primary `cs.RO` (Robotics). Optional cross-list `cs.LG`.
3. **Endorsement (first submission to cs.RO).** arXiv requires endorsement before a first submission to a
   category. Per the endorsement page:
   - start a new submission and choose `cs.RO`; arXiv then emails an *endorsement request* with a six-character
     code and a link;
   - send that email to one person you know who is an active arXiv author in the area (the page suggests the
     thesis advisor or another professor in your department). The "Which authors of this paper are endorsers?" link
     at the bottom of any arXiv abstract page shows who can endorse; for example the abstract pages of the papers
     cited here (ACT 2304.13705, Diffusion Policy 2303.04137);
   - do not email many endorsers at once or repeat requests; one positive endorsement is enough;
   - you may include the PDF or the GitHub link with the request.
   arXiv published an updated endorsement policy in January 2026
   (https://blog.arxiv.org/2026/01/21/attention-authors-updated-endorsement-policy) - **not read; check it before
   starting.**
4. **Upload.** A `.zip`/`.tar.gz` with: `main.tex`, `main.bbl` (arXiv does not run BibTeX, so the
   `.bbl` is required; it is committed here and regenerated by `tectonic -X compile --keep-intermediates main.tex`), `refs.bib`,
   `IEEEtranH.bst`, `fig_scene.png`, `fig_success.pdf`, `fig_failures.pdf`, `fig_force.pdf`.
5. **Metadata.** Title and abstract as in `main.tex` (plain text in the abstract field; write "p = 2.9e-5" instead of
   LaTeX). Comments field, e.g.: "5 pages, 4 figures, 3 tables. Simulation study. Code and per-episode results:
   https://github.com/pavanyadava007/assembly-lab". License: CC BY 4.0 or the arXiv non-exclusive license.
6. **Before you click submit:** read the PDF arXiv generates, check that the author line and email are right, and
   check the workshop's policy if you also submit there (below).

## Workshops with deadlines after 2026-10-03 (all CoRL 2026, Austin, TX)

All three are **within one week**. All three review double-blind or ask for 4 pages of main text, so a workshop
version needs (a) the author block and the GitHub link removed or anonymized, and (b) the main text cut from about
4.4 pages to 4 (for example drop the Discussion subsection "What the paired evaluation adds" and shorten the
simulation-fixes paragraph). Deadlines below were read from the workshop pages on 2026-10-03.

| Workshop | Deadline | Format | Fit | URL |
|---|---|---|---|---|
| Everything Beneath the Policy: How Controllers, Hardware, and Data Infrastructure Shape Robot Learning | **9 Oct 2026, 23:59 US Central Time** (OpenReview); notification 26 Oct; workshop 12 Nov | 4 pages main text, references/appendix extra; CoRL 2026 or IEEEtran conference template; double-blind; concurrent submissions allowed if disclosed | Best fit: the CFP asks for controlled studies of controllers, observation spaces and evaluation protocols, and for negative results; the position-vs-impedance and F/T results match | https://beneath-the-policy.github.io/ (submit: https://openreview.net/group?id=robot-learning.org/CoRL/2026/Workshop/WEBP) |
| Open Problems in Contact-Rich Loco-Manipulation | **8 Oct 2026, AoE** (OpenReview); notification 22 Oct; camera-ready 27 Oct | 2-4 pages main content, IEEE two-column template; negative results and failure analyses welcome | Partial fit: contact-rich and force sensing, but the workshop centres on legged/mobile robots; ours is a fixed-base arm | https://contact-rich-loco-manipulation.github.io/call/index.html |
| Bringing Physics Simulation and World Models Together for Robotic Manipulation | **7 Oct 2026, 23:59 AoE** | up to 4 pages excluding references; CoRL 2026 template encouraged; double-anonymized | Moderate fit: simulation-based manipulation study and the simulation fixes; no world model in this work | https://corl26ws-physwm.github.io/ |

Not verified / not included:
- "Small Data, Rich Sensing: Multimodal Learning for Robotic Manipulation" (https://multimodal-learn.github.io/,
  CoRL 2026, 9 Nov) explicitly asks for F/T ablations and negative results, which fits well, but its submission

  (https://www.corl.org/program/workshops). Check again before relying on it.
- ICRA 2027 workshops usually have spring deadlines; none were checked. **Unverified.**

Whether a workshop allows the paper to be on arXiv at the same time is not stated on the three pages above;
ask the organizers if it matters (double-blind reviewing usually tolerates arXiv preprints, but this is
**unverified** for these workshops).
